# GitHub Résumé Generator

Compile your GitHub profile into a perfect, vector-PDF résumé — entirely in the browser. Zero servers, zero tracking.

[![Vector PDF](https://img.shields.io/badge/PDF-vector%20%2F%20searchable-111111)]() [![Tech](https://img.shields.io/badge/Vite%205-React%2018-FAFAFA)]() [![License](https://img.shields.io/badge/license-MIT-888888)]()

```
github.com/torvalds  →  torvalds-resume.pdf  (~50 KB, vector)
```

## Highlights

- **Engineered Precision aesthetic.** Linear/Vercel-style light mode — pure `#FFFFFF` canvas, 1px `#EAEAEA` borders, Tungsten Black (`#111111`) ink, no accent colors. Sharp `rounded-md/lg/xl` corners. No gradients, no glassmorphism, no glow blobs.
- **True vector PDF.** Generated by `@react-pdf/renderer` — selectable, searchable, prints sharp at any size. Typical output ~50 KB.
- **Single source of truth.** `<ResumeView>` (HTML/Tailwind) and `<ResumeDocument>` (PDF) consume the same `ResumeData` shape and the same `ThemeTokens`.
- **Three themes**: **Vercel** (Inter), **Linear** (Geist), **Monospace** (Geist Mono) — all pure white background, ink-black text, grayscale stepped-opacity language bar.
- **Single GraphQL query** to GitHub for profile, contributions, pinned repos, top repos, languages, organizations, and rate-limit info.
- **Token stays client-side.** PAT stored in `localStorage` only, posted only to `https://api.github.com/graphql`.
- **Zero CLS.** Skeleton wireframe matches the résumé layout pixel-for-pixel.
- **Code-split.** `react-pdf` (~490 KB gz) is dynamically imported only on Download click. Main bundle stays small.

## Stack

Vite 5 · React 18 · TypeScript (strict, no `any`) · Tailwind CSS · Framer Motion · `@react-pdf/renderer` · `@tanstack/react-query` · `graphql-request` · Zustand · `lucide-react`.

## Quickstart

Requires Node ≥ 18.

```bash
npm install
bash scripts/fetch-fonts.sh   # one-time: pulls 11 OFL .ttf files (~3 MB) into public/fonts/
npm run dev                   # http://localhost:5173
```

Production:

```bash
npm run build && npm run preview   # http://localhost:4173
```

Quality gates: `npm run typecheck`, `npm run lint`.

## GitHub Personal Access Token

Without a PAT GitHub limits anonymous IPs to 60 requests/hour. With a token: 5,000/hour.

Generate one at [github.com/settings/tokens/new](https://github.com/settings/tokens/new?scopes=public_repo,read:user&description=GitHub%20R%C3%A9sum%C3%A9) with classic scopes:

- `public_repo`
- `read:user`

Click **CONFIGURE_AUTH_TOKEN** on the home page (or **Token** in the top bar of the résumé view) and paste it in. The token is stored in `localStorage` under the key `gh_pat_v1` and only sent to `https://api.github.com/graphql` (runtime URL assertion in `client.ts`).

For dev, you can also drop it into `.env.local`:

```
VITE_GITHUB_TOKEN=ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

## Themes

| ID | Heading font | Body font | Notes |
|---|---|---|---|
| `vercel` (default) | Inter SemiBold | Inter | Generous whitespace, ink-black links |
| `linear` | Geist | Geist | Tighter `-0.02em` heading tracking, denser layout |
| `monospace` | Geist Mono | Geist Mono | Mono everywhere, terminal-clean |

All three render on pure white paper and use ink-black as the only accent. The stacked language bar uses grayscale stepped opacity (no chromatic accent).

## Architecture

```
src/
├── resume/
│   ├── types.ts                # ResumeData (the contract)
│   ├── normalize.ts            # GraphQL → ResumeData
│   ├── ResumeView.tsx          # On-screen renderer
│   ├── sections/               # Header, Stats, Languages, Pinned, …
│   ├── pdf/
│   │   ├── ResumeDocument.tsx  # PDF renderer
│   │   ├── styles.ts           # StyleSheet.create() per theme
│   │   └── fonts.ts            # Font.register() of self-hosted .ttf
│   └── themes/                 # vercel / linear / monospace token sets
├── github/                     # client + queries + rate-limit helpers
├── components/                 # UsernameInput, TokenDialog, ThemeSwitcher, ExportBar, …
├── store/                      # zustand (token, prefs)
├── lib/                        # pdfDownload, urlToDataUrl, motion, format helpers
├── routes/                     # Home, Resume
├── App.tsx
└── main.tsx                    # QueryClient + Router + Buffer polyfill
```

`ResumeData` is normalised once and consumed by both renderers. Themes are just data: `<ResumeView>` reads them through CSS variables; `<ResumeDocument>` reads them through `StyleSheet.create()`.

## Deploy

### Vercel

1. Push to GitHub.
2. Import on Vercel — Vite is auto-detected.
3. The included `vercel.json` rewrites unknown paths to `/index.html` so deep links like `/u/torvalds` work on hard reloads.

### GitHub Pages

A workflow at `.github/workflows/pages.yml` builds and deploys on every push to `main`. Enable Pages → "GitHub Actions" in the repo settings.

## What's *not* used (and why)

- ❌ `html2canvas` / `jsPDF` / `react-to-pdf` — all rasterize HTML; output is heavy and not searchable.
- ❌ Chart libraries — the language bar is plain `<View>` rectangles with stepped opacity for total control.
- ❌ External font CDNs at runtime — fonts ship in `public/fonts/` (Geist, Geist Mono, Inter, IBM Plex Serif, JetBrains Mono — all OFL-licensed).
- ❌ Gradients, blurs, glow blobs, glass surfaces — explicitly forbidden by the design brief.
